# fdt

Placeholder for https://w3id.org/fdt/ (FAIR Data Train). Its rules still live
in ids/fdt/.htaccess at w3id.org and are NOT forwarded here. Before switching
w3id.org to the forwarding rule, copy those rules into rules/fdt/.htaccess
with a tests.yaml, and check them with `python3 -m pidrelay test --only fdt`.
